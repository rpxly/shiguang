## 调研：拾光产品探索方向清单 评审 + 端侧 AI 可行性复核

**评审结论（方向清单）**：结构可进评审，但三类证据强度混杂（竞品事实 / 标注为「示例数据」的 62%-41% 漏斗 / 1-5 定性判断被写成百分比）需分开标注。建议方向 2（回忆触发器）先上，方向 1（AI 叙事）先做 POC。

**端侧 AI 可行性（本机实测核实，非文档口径）**：
- 项目工具链实测：Flutter 3.22.3 / Dart 3.4.4；AGP 8.4.0 / Gradle 8.6 / Kotlin 1.9.20；minSdk 26 / compileSdk 36；`ndkVersion = "26.1.10909125"` 已声明**但本机未安装**（`Android/sdk/ndk`、`sdk/cmake`、`cmdline-tools` 均不存在）。
- `llama_cpp_dart` 0.2.2：env sdk `>=3.2.0 <4.0.0`，与 Dart 3.4.4 兼容；无预编译库，README 明确要求自编译 llama.cpp 共享库 → 唯一兼容当前工具链的路线，但需自建 NDK 编译 + 按 ABI 打包 .so。
- `llamadart` 0.16.4（2026-10-26 发布，最活跃）：要求 Dart `^3.10.7`，需 Flutter 升级，当前不可用。
- `llama_flutter_android` 0.2.6：唯一「零手工编译」路线（插件自带 llama.cpp 源码，android/CMakeLists.txt 走 externalNativeBuild），但要求 Flutter ≥3.24，且插件自身 AGP 8.9.1 + Kotlin 2.1.0，与项目 AGP 8.4/Gradle 8.6 冲突；`abiFilters = ["arm64-v8a"]` 仅 arm64，32 位机不支持；已含 16KB page 对齐标志（`-Wl,-z,max-page-size=16384`）与 Vulkan 探测 API。
- 模型分发：huggingface.co 不可达（超时），modelscope.cn（302）/ hf-mirror.com（200）可用，走国内源可行。

**技术判断**：端侧 LLM 可实现，但真实约束是「1.1GB 下载 + 1.1–1.4GB 常驻 + arm64 only + 中低端机 90–180s 等待」，而非可否问题。建议把首个落点从「整篇叙事月刊」收缩为「3–5 句摘要 / 一句话标题」（30–60 token，2–5s 出结果），低端机走 scene_tag 规则模板兜底。

**待办**：文档需修正 7.3「minSdk 26 就绪」表述、7.4 Phase 0 补 NDK/CMake 前置、7.1 补两个替代插件及版本门槛。
