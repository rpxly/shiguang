**2. GlassCard paint 崩溃（真 bug，比水印测试重要）**：
- 根因：`lib/components/glass_card.dart` 的 `foregroundDecoration` 同时给 `borderRadius` 与上下不同色的 `Border(top/bottom)` → Flutter 在 paint 阶段断言 `A borderRadius can only be given on borders with uniform colors`。
- 影响面：**全站每一张玻璃卡片**在 debug 下都会 paint 失败（release 因 assert 剥离不暴露），水印页 13 例测试失败只是它的一个出口。
- 修法：移除非法 `foregroundDecoration`，新增 `_GlassHairlinePainter`（`clipRRect` 后画上下两条 1px 横线），视觉等价、不触发断言。
- 新增守卫 `test/glass_card_paint_test.dart`（含渐变卡片分支），断言 `tester.takeException()` 为 null。

**验证**：全量 `flutter test` **89 例全绿**（此前 74 通过 / 13 失败）；`flutter analyze lib/ test/` 0 error / 0 warning，49 条 info 全为 theme.dart 既有风格项。
