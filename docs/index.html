Features

像整理一本杂志那样，整理你的相册

三个 Tab，覆盖从「一万张乱成一团」到「可以分享」的完整链路。

🃏

卡片式快速整理

左滑删除、右滑收藏、上滑保留、拖入相簿 — 像洗牌一样处理堆积的照片，批量延迟删除，随时撤销。

🗂️

按月份整理与相簿

未整理的照片按月份归组、逐月清零；相簿创建、重命名、排序，精选照片一墙收藏。

🧹

清理建议

自动识别截图与低质照片，分批给出清理建议，把相册的「库存」还给值得留下的瞬间。

📖

月刊编辑器

6 种杂志模板（下留白 / 全幅 / 拍立得 / 中线 / 立体相框 / 胶片质感），「时光线」一键成刊，实时预览，一键导出 PNG 分享。

🧠

智能摘要与月度回顾

心情、天气、步数、出行与重要事件 — 月度卡只陈述照片事实，配一句恰如其分的文案。

✍️

文案库

内置 170 条精选文案，覆盖哲思、旅行、爱情等 9 大分类；联网热句抓取，随机分配进月刊不重样。

🎞️

胶片索引与胶片质感

按月浏览全部照片的胶片索引页；柯达的暖、富士的绿、伊尔福的黑白 — 4 种胶片品牌质感。

🖼️

杂志风水印

相机时间地点水印、杂志风边框与浮层，EXIF 信息完整保留 — 拍照即盖章，分享即成片。

🌗

明暗双主题

完整的亮色 / 暗色模式，液态玻璃材质全局协调，深夜翻相册也不刺眼。

Local First

照片在你的手机里，
回忆也留在你的手机里。

拾光没有账号系统，没有云端同步 — 所有照片、相簿、月刊与使用记录都保存在本机数据库中。场景识别在设备上离线完成，月度摘要只陈述照片事实。它读得到你的十月，但互联网读不到。

✓
无账号 · 无上传打开即用，照片与整理记录全部存于本机 Hive 数据库。
✓
离线场景识别ML Kit 在设备上完成标签与场景词识别，不需要联网。
✓
只陈述照片事实月度摘要从场景、出行、天气、步数中提炼，不编造你的回忆。
✓
轻量联网，仅取文案唯一的网络请求是 hitokoto 一句话文案 — 与你的照片无关。
